1. Voting Eligibility

User se age input lo.

Age ≥ 18 → "You can vote"
Age < 18 → "You cannot vote"

2. Pass / Fail

Student ke marks input lo.

Marks ≥ 40 → "Pass"
Marks < 40 → "Fail"

3. Grade Calculator

Marks ke according grade print karo:

90–100 → A
75–89 → B
60–74 → C
40–59 → D
Below 40 → Fail

4. ATM Withdrawal

Balance और withdrawal amount input लो।

Amount ≤ balance → "Withdrawal successful"
Amount > balance → "Insufficient balance"

5. Login System

Username और password input लो।

username = "admin"
password = "1234"
दोनों सही → "Login successful"
Username गलत → "Invalid username"
Password गलत → "Invalid password"

6. Temperature

Temperature input लो:

≥ 40 → "Very Hot"
30–39 → "Hot"
20–29 → "Normal"
< 20 → "Cold"

7. Shopping Discount

Shopping amount input लो:

₹5000 या ज्यादा → 20% discount
₹3000–4999 → 10% discount
₹1000–2999 → 5% discount
Below ₹1000 → No discount

Bonus: Final amount भी calculate करो।

8. Electricity Bill

Units input लो:

0–100 → ₹5/unit
101–200 → ₹7/unit
201–300 → ₹10/unit
Above 300 → ₹12/unit

Total electricity bill calculate करो।

9. ATM PIN

User से PIN input लो।

correct_pin = 1234
सही PIN → "Access Granted"
गलत PIN → "Wrong PIN"

अगर 3 attempts तक गलत PIN हो तो:

"Card Blocked"

10. Railway Ticket Fare

Age input लो:

Age < 5 → Free
5–12 → 50% fare
13–59 → Full fare
60+ → 40% discount

Base fare ₹500 मानकर final fare calculate करो।
